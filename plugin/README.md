# Simplified Technical Hebrew (ASD-STE100) plugin

This folder is the plugin for Anthropic's plugin directory. The script `scripts/build-plugin.py` makes it from the files at the root of the repository. Do not edit this folder by hand.

This plugin does not include the linter `scripts/ste-lint-he.py`. The plugin directory accepts code files only from Verified organizations. To get the skill with the linter, install it from the root of the repository `g4lb/asd-ste100-hebrew-skill`.
