# ASD-STE100 בעברית — עברית טכנית פשוטה לפלט של סוכנים

סקיל ל-Claude Code שמנסח מחדש טקסט עברי צפוף או דו-משמעי בעברית טכנית פשוטה. הסקיל מבוסס על [ASD-STE100](https://www.asd-ste100.org/), תקן השפה המבוקרת שתעשיית התעופה בנתה כדי שאי אפשר יהיה לטעות בהוראות תחזוקה.

הקורא כאן שונה: **סוכן AI** שקורא טקסט בעברית בלי אדם שיפתור דו-משמעות, וגם קורא אנושי של טקסט טכני, כולל קוראים שהעברית אינה שפת האם שלהם.

> ASD-STE100 מגדיר אנגלית בלבד. אין גרסה רשמית בעברית. כל כללי העברית כאן הם התאמה של הפרויקט, לא תקן רשמי.

## מה הסקיל עושה

1. בוחר מצב: **קפדני** להוראות, הודעות שגיאה ותיאורי כלים. **גמיש** ל-README ולטקסט הסברי.
2. מסמן כל הפרה: מילים נרדפות שמתחלפות, צורות סביל, שמות פעולה (`לבצע בדיקה`), שרשראות סמיכות ארוכות, שרשראות של ש-, משפטים ארוכים, נקודה-פסיק, סלנג ומילים לועזיות, קיצורים, תחילית בלי מקף לפני לועזית (`בAPI`), וצורות הוראה מעורבות.
3. מנסח מחדש בלי להשמיט עובדה, תנאי או הסתייגות. `ייתכן ש…` נשאר `ייתכן ש…`.
4. מחזיר רק את הטקסט החדש. כדי לראות את הכללים, בקשו "הסבר את השינויים" או "show the diff".

### כללים שמיוחדים לעברית

- **צורת הוראה אחת: שם הפועל** (`לפתוח את הקובץ`). שם הפועל נייטרלי מבחינת מגדר. לא מערבבים אותו עם `פתח`, `תפתח` או `יש לפתוח`.
- **מקף אחרי תחילית לפני לועזית או ספרה**: `ב-API`, `ה-JSON`, `ב-2025`.
- **אין קיצורים**: `בדרך כלל`, לא `בד"כ`.
- **כתיב מלא**. אם מילה עדיין דו-משמעית, מנסחים אחרת או מנקדים את המילה הזו בלבד.
- **פסוקית ש- אחת לכל היותר במשפט.**
- **עד 16 מילים** במשפט הוראה, ו**עד 20 מילים** במשפט תיאור.

הרשימה המלאה: [`references/writing-rules.md`](references/writing-rules.md).

## הלינטר

`scripts/ste-lint-he.py` משתמש רק בספרייה הסטנדרטית של Python.

```bash
python3 scripts/ste-lint-he.py FILE.md
echo "לבצע בדיקה של הקובץ; ב2025" | python3 scripts/ste-lint-he.py --json
python3 scripts/ste-lint-he.py --selftest
```

- **חובה** (מכשילים את הריצה): נקודה-פסיק, אורך משפט, שמות פעולה (`לבצע בדיקה`), מילות שיווק, מקף אחרי תחילית, סלנג, מילים נרדפות שמתחלפות, `או`, `וגם` או `וכן` בסוף פריט ברשימה.
- **המלצה** (לא מכשילים): סביל, קיצורים, שרשרת ש-, ו-`לבצע` לפני מילה שאינה שם פעולה מוכר (`לבצע את הפקודה`).
- `--baseline N` מתיר N הפרות חובה. `--disable rule1,rule2` משתיק כללים.
- הלינטר **לעולם לא** מסמן הסתייגויות (`ייתכן`, `עשוי`, `אולי`): רמת הביטחון היא חלק מהתוכן.
- הלינטר **לא** בודק אורך של שרשרת סמיכות, הומוגרפים, גוף שלישי רבים סתמי (`מוחקים`), השמטה של `את`, או את כלל שם הפועל. הבדיקות האלה דורשות ניתוח מורפולוגי, ולכן בודקים אותן ידנית.
- תוצאה בלי הפרות אומרת רק שהבדיקות המבניות לא מצאו בעיה. היא לא מוכיחה שהמשמעות נשמרה.

## היקף

מתאים ל: הודעות בין סוכנים, תיאורי כלים, הודעות שגיאה, פרומפטים, נהלים וטקסט ממשק בעברית.

לא מתאים ל: כתיבה יוצרת, שיווק, או טקסט באנגלית (בשביל אנגלית יש את [asd-ste100-skill](https://github.com/danyuchn/asd-ste100-skill)).

הסקיל מתקן את הצורה, לא את התוכן. פסקה ריקה תצא קצרה, נקייה, ועדיין ריקה.

## English summary

A Claude Code skill that rewrites dense or ambiguous **Hebrew** into Simplified Technical Hebrew, adapted from ASD-STE100 and from [danyuchn/asd-ste100-skill](https://github.com/danyuchn/asd-ste100-skill). It includes a stdlib-only linter (`scripts/ste-lint-he.py`). ASD-STE100 defines English only, so the Hebrew rules are this project's adaptation, not an official standard. MIT licence.
